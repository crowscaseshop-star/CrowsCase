# Crow's Case — ระบบจัดการการขาย (ธีมดำ-ทอง)

เว็บแอปจัดการการขายแบบครบวงจร ทำงานได้ทันทีโดยไม่ต้องติดตั้งอะไรเพิ่ม
(HTML/CSS/JavaScript ล้วน — เก็บข้อมูลใน localStorage ของเบราว์เซอร์)

## วิธีเปิดใช้งาน

ดับเบิลคลิกไฟล์ **`index.html`** → เข้าสู่ระบบ

| ชื่อผู้ใช้ | รหัสผ่าน | ตำแหน่ง | เห็นเมนู |
|---|---|---|---|
| `admin` | `1234` | เจ้าของร้าน | ทุกเมนู + สิทธิ์เต็ม |
| `manager` | `1234` | ผู้จัดการ | ทุกอย่างยกเว้นจัดการพนักงาน/ตั้งค่าเว็บไซต์ |
| `staff` | `1234` | พนักงานขาย | ภาพรวม, รายการขาย, ประวัติ, Order Online |

> ⚠️ เปลี่ยนรหัสผ่าน `admin` ทันทีก่อนใช้งานจริง (เมนู จัดการพนักงาน → ปุ่ม "รหัสผ่าน")

**หน้าสำหรับลูกค้า:** `order.html` — ส่งลิงก์นี้ให้ลูกค้าสั่งซื้อออนไลน์

## 🖤 การใส่โลโก้ร้าน (สำคัญ)

ระบบใช้โลโก้ไฟล์เดียวกับทุกหน้า — **หน้าเข้าสู่ระบบ, แถบเมนูแดชบอร์ด, หน้าเว็บลูกค้า (แถบบน / หน้าเกี่ยวกับ / ท้ายเว็บ), ใบเสร็จ และไอคอนแท็บเบราว์เซอร์**

**วิธีใส่:** บันทึกไฟล์โลโก้ลงที่

```
assets/img/logo.png
```

เท่านี้ทุกหน้าจะเปลี่ยนเป็นโลโก้ของคุณทันที (แนะนำไฟล์สี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใสหรือสีดำ ขนาดอย่างน้อย 512×512)

- ถ้ายังไม่มีไฟล์นี้ ระบบจะใช้โลโก้สำรอง `assets/img/logo.svg` (อีกาในเคสการ์ด สีดำ-ทอง) ที่มาให้แล้วโดยอัตโนมัติ
- หรืออัปโหลดผ่าน **จัดการเว็บไซต์ → โลโก้ & เอกลักษณ์แบรนด์ → อัปโหลดไฟล์จากเครื่อง**
  (วิธีนี้เห็นเฉพาะเบราว์เซอร์เครื่องนั้น — ถ้าจะให้ลูกค้าทุกคนเห็นบนเว็บจริง ต้องวางไฟล์ที่ `assets/img/logo.png`)
- เปลี่ยนเป็นไฟล์ชื่ออื่นหรือลิงก์ภายนอกก็ได้ ที่ช่อง “ที่อยู่ไฟล์โลโก้”

## เมนูและความสามารถ

### ◆ ภาพรวม
- KPI: ยอดขายวันนี้ (เทียบเมื่อวาน), ยอดขายเดือนนี้, กำไรขั้นต้น, รายการที่ต้องจัดการด่วน
- กราฟยอดขาย 14 วัน, สินค้าขายดี 30 วัน, สัดส่วนช่องทางขาย, วิธีชำระเงินยอดนิยม
- **คำแนะนำอัตโนมัติ "สินค้าที่ควรมี"** วิเคราะห์จากยอดขายจริง 30 วัน:
  - **ควรสั่งเข้าเพิ่ม** — คำนวณความเร็วขาย (ชิ้น/วัน) เทียบกับของคงเหลือ บอกว่าของจะหมดในกี่วันและควรสั่งเพิ่มกี่ชิ้น
  - **ควรเร่งขาย/จัดโปร** — สินค้าที่กำไรขั้นต้น ≥ 45%
  - **สินค้าไม่เคลื่อนไหว** — ไม่ขายได้เลยใน 30 วัน พร้อมมูลค่าที่จมทุน
  - สรุปว่าหมวดหมู่ไหนทำเงินสูงสุด ควรเพิ่มสินค้าหมวดใดก่อน

### ▣ รายการขาย (หน้าขายจริง)
- เลือกสินค้าจากตาราง ค้นหาด้วยชื่อหรือ SKU (พิมพ์ SKU แล้วกด Enter = เพิ่มเข้าตะกร้าทันที รองรับเครื่องสแกนบาร์โค้ด)
- กรองตามหมวดหมู่, ตะกร้าปรับจำนวน, ส่วนลด (ตามสิทธิ์), VAT (เปิด/ปิดได้)
- เลือกวิธีชำระเงิน + ช่องทางขาย, ใส่ชื่อลูกค้า, คำนวณเงินทอน
- **พักบิล** — พักหลายบิลพร้อมกันแล้วเรียกคืนภายหลัง
- ตัดสต๊อกอัตโนมัติ + ออกใบเสร็จพร้อมสั่งพิมพ์

### ≡ ประวัติการขาย
- บันทึกทุกบิลอัตโนมัติ พร้อมชื่อพนักงานที่ขาย
- กรองตามช่วงวันที่ / พนักงาน / ช่องทาง / สถานะ + ค้นหาข้อความ
- สรุปยอด: จำนวนบิล, ยอดขายรวม, เฉลี่ยต่อบิล, กำไรขั้นต้น (เฉพาะผู้มีสิทธิ์)
- คลิกที่บิลเพื่อดูรายละเอียด → พิมพ์ใบเสร็จซ้ำ / ยกเลิกบิล (คืนสต๊อกอัตโนมัติ พร้อมบังคับระบุเหตุผล)
- ส่งออก CSV เข้าโปรแกรมบัญชี

### ▤ สต๊อกสินค้า
- เพิ่ม / แก้ไข / ลบสินค้า, ตั้งราคาทุน-ราคาขาย, จำนวน, หน่วยนับ, หมวดหมู่
- รูปสินค้า: ใช้อีโมจิ, ลิงก์รูป หรืออัปโหลดไฟล์จากเครื่อง
- **จุดสั่งซื้อขั้นต่ำ** — ต่ำกว่าค่านี้ระบบขึ้นตัวเลขแจ้งเตือนบนเมนูทันที
- ปุ่ม ± สำหรับ รับสินค้าเข้า / ตัดของเสีย / ตรวจนับตั้งค่าใหม่ พร้อมหมายเหตุ
- ทุกความเคลื่อนไหวบันทึกชื่อผู้ทำรายการ ตรวจย้อนหลังได้
- มูลค่าสต๊อกตามต้นทุนและตามราคาขาย + ส่งออก CSV

### 🌐 เว็บไซต์ลูกค้า — 4 เมนู แยกเป็น 3 หน้า

| เมนู | เนื้อหา | แก้ไขได้ที่ |
|---|---|---|
| **หน้าแรก** (order.html) | ฉากใหญ่นำเสนอ**สินค้าเด่นที่สุด** พร้อมรูป ราคา ปุ่มสั่งซื้อ + จุดแข็งร้าน 3 ข้อ | จัดการเว็บไซต์ → หน้าแรก (เลือกสินค้าเด่น/หัวข้อ/คำโปรย/ข้อความปุ่ม) |
| **เลือกซื้อ** (shop.html) | เฉพาะสินค้าที่เปิดขายอยู่ พร้อมราคาทุกชิ้น + ค้นหา + กรองหมวดหมู่ + ขั้นตอนสั่งซื้อ | สต๊อกสินค้า (สินค้าที่เปิดใช้งานจะขึ้นอัตโนมัติ) |
| **เกี่ยวกับ** (about.html) | เรื่องราวก่อนจะมาเป็น Crow's Case + ปีที่ก่อตั้ง + จุดเด่น 3 ข้อ | จัดการเว็บไซต์ → เกี่ยวกับ |
| **ติดต่อ** (about.html#contact) | การ์ด LINE / Facebook / เบอร์โทร (กดแล้วเปิดแอปทันที) + ที่อยู่ + เวลาทำการ + แผนที่ — อยู่หน้าเดียวกับเกี่ยวกับ | จัดการเว็บไซต์ → ติดต่อ |

แต่ละเมนูเป็นคนละหน้า (คนละ URL) แชร์ลิงก์เฉพาะหน้าได้ • **ตะกร้าติดตามข้ามหน้า** เลือกสินค้าหน้าแรกแล้วไปหน้าเลือกซื้อต่อได้ ของไม่หาย • ภาพพื้นหลังแบรนด์อยู่ครบทุกหน้า • แก้ข้อมูลในแดชบอร์ดแล้วหน้าเว็บอัปเดตตามทันที

**🌐 รองรับ 3 ภาษา** — ลูกค้ากดสลับ **ไทย / EN / 中文** ได้ที่มุมขวาบน ระบบจำภาษาที่เลือกไว้ให้ • ข้อความประจำหน้าเว็บ (เมนู ปุ่ม ฟอร์ม ขั้นตอนสั่งซื้อ ข้อความแจ้งเตือน) แปลไว้ครบทั้ง 3 ภาษาแล้ว • เนื้อหาที่เขียนเอง (หัวข้อหน้าแรก/เกี่ยวกับ) กรอกคำแปลได้ที่ **จัดการเว็บไซต์ → เนื้อหาหลายภาษา** เว้นว่างจะใช้ภาษาไทยแทน • ชื่อสินค้าและหมวดหมู่แสดงตามที่กรอกในสต๊อกทุกภาษา

### ✦ Order Online (หลังร้าน)
- ลูกค้าเลือกสินค้า (มีรูปสินค้าแสดง) → กรอกชื่อ + เบอร์โทร + หมายเหตุ → ส่งคำสั่งซื้อ
- ออเดอร์เข้าหลังร้านทันที พร้อม **รูปสินค้าที่ลูกค้าเลือก**, ยอดรวม, เวลาที่สั่ง
- สถานะ: ใหม่(รอติดต่อ) → ติดต่อแล้ว → ยืนยัน → ปิดการขาย / ยกเลิก
- ปุ่มโทรออกทันทีจากเบอร์ลูกค้า, บันทึกหมายเหตุการติดต่อ
- **ปิดการขาย** = สร้างบิลขาย + ตัดสต๊อก + ออกใบเสร็จให้อัตโนมัติ
- ออเดอร์ค้างเกิน 24 ชั่วโมงจะถูกไฮไลต์สีแดงเตือน
- ปุ่มคัดลอกลิงก์หน้าร้านสำหรับส่งให้ลูกค้า

### ☗ จัดการพนักงาน
- สร้างบัญชีพนักงานได้ไม่จำกัด (ชื่อ, username, รหัสผ่าน, เบอร์โทร)
- **ตำแหน่งสำเร็จรูป**: เจ้าของร้าน / ผู้จัดการ / พนักงานขาย / พนักงานคลัง / กำหนดเอง
- **เลือกเมนูที่พนักงานแต่ละคนมองเห็นได้ทีละเมนู** (8 เมนู)
- **สิทธิ์รายข้อ 10 รายการ** — ข้อมูลเชิงลึกที่มีเครื่องหมาย 🔒 ควรจำกัด:
  - 🔒 แก้ไขราคา & ต้นทุน, 🔒 ลบสินค้า, 🔒 ยกเลิก/คืนบิล, 🔒 ดูต้นทุนและกำไร
  - เพิ่มสินค้า, แก้ไขข้อมูลสินค้า, ปรับสต๊อก, ให้ส่วนลด, จัดการออเดอร์, ส่งออกข้อมูล
- พนักงานที่ไม่มีสิทธิ์: ปุ่มจะไม่แสดง ช่องราคาจะถูกล็อก และคอลัมน์ต้นทุน/กำไรจะถูกซ่อนทั้งระบบ
- ระงับบัญชี (แทนการลบ) / เปลี่ยนรหัสผ่าน / ดูเวลาเข้าระบบล่าสุด
- ระบบป้องกันไม่ให้ลบหรือลดตำแหน่งเจ้าของร้านคนสุดท้าย

### ⚙ จัดการเว็บไซต์
- **โลโก้ & แบรนด์** — อัปโหลด/ตั้ง path โลโก้, ชื่อร้าน, สโลแกน, สกุลเงิน
- **หน้าแรก** — เลือกสินค้าเด่นที่โชว์, ป้ายกำกับ, หัวข้อ, คำโปรย, ข้อความปุ่ม
- **เกี่ยวกับ** — หัวข้อ, ปีก่อตั้ง, เนื้อหาหลายย่อหน้า, จุดเด่น 3 ข้อ
- **ติดต่อ** — เบอร์โทร, LINE ID + ลิงก์, Facebook + ลิงก์, อีเมล, ที่อยู่, แผนที่, เวลาทำการ
- เปิด-ปิด VAT และตั้งอัตรา, เปิด-ปิดการแจ้งเตือนสินค้าใกล้หมด
- เลือกเฉดสีทอง 5 แบบ (ทองคลาสสิก / ทองอ่อน / ทองเข้ม / แชมเปญ / ทองแดง)
- จัดการหมวดหมู่สินค้า
- **สำรองข้อมูล (.json) / กู้คืน / ล้างข้อมูลเริ่มใหม่**

## ☁ ฐานข้อมูลกลาง & ซิงก์เรียลไทม์ (Supabase)

ระบบรองรับ 2 โหมด สลับอัตโนมัติตามว่าตั้งค่า `assets/js/config.js` ไว้หรือยัง

| | โหมดออฟไลน์ (ค่าเริ่มต้น) | โหมด Supabase |
|---|---|---|
| ที่เก็บข้อมูล | เบราว์เซอร์เครื่องเดียว | Postgres บนคลาวด์ |
| หลายเครื่องพร้อมกัน | ไม่ได้ | ได้ เห็นข้อมูลชุดเดียวกัน |
| ออเดอร์จากลูกค้าบนเว็บจริง | ไม่เข้ามาที่ร้าน | เด้งเข้าเมนู Order Online ทันที |
| ล็อกอินพนักงาน | username + รหัสผ่าน | อีเมล + รหัสผ่าน (Supabase Auth) |
| ความปลอดภัยข้อมูล | อยู่ในเครื่อง | RLS จำกัดสิทธิ์ระดับฐานข้อมูล |

### วิธีเปิดใช้งาน (ทำครั้งเดียว)

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) — เลือกภูมิภาค **Singapore** จะเร็วที่สุดสำหรับผู้ใช้ในไทย
2. เปิด **SQL Editor** → วางไฟล์ `supabase/schema.sql` ทั้งไฟล์ → Run
   (สร้างตาราง 7 ตาราง + นโยบายสิทธิ์ RLS + เปิด Realtime ให้ครบในคำสั่งเดียว)
3. **Authentication → Users → Add user** สร้างบัญชีเจ้าของร้าน (ติ๊ก Auto Confirm)
   แล้วรันคำสั่ง `insert into public.staff ...` ที่อยู่ท้ายไฟล์ schema.sql โดยใส่ UID ของผู้ใช้นั้น
4. **Authentication → Providers → Email** ปิด *Confirm email*
   (เพื่อให้สร้างบัญชีพนักงานจากในแอปแล้วใช้งานได้ทันที)
5. **Project Settings → API** คัดลอก *Project URL* และ *anon key* มาใส่ใน `assets/js/config.js`

> ⚠️ ใช้ **anon key** เท่านั้น (ออกแบบมาให้ฝังในเว็บได้ ความปลอดภัยคุมด้วย RLS)
> **ห้ามใส่ service_role key** ในไฟล์นี้เด็ดขาด เพราะ key นั้นข้ามทุกสิทธิ์และไฟล์นี้เปิดเผยสู่สาธารณะ

### สิทธิ์ที่ตั้งไว้ในฐานข้อมูล (RLS)

| ตาราง | ลูกค้าทั่วไป (ไม่ล็อกอิน) | พนักงาน | เจ้าของร้าน |
|---|---|---|---|
| products, settings | อ่านได้ | อ่าน+เขียน | อ่าน+เขียน |
| orders | **สร้างได้อย่างเดียว** | อ่าน/แก้/ลบ | อ่าน/แก้/ลบ |
| sales, stock_logs, activity | เข้าไม่ได้ | อ่าน+เขียน | อ่าน+เขียน |
| staff | เข้าไม่ได้ | อ่าน + แก้ของตัวเอง | สร้าง/แก้/ลบทุกคน |

### หมายเหตุ

- ระบบซิงก์ทำงานแบบ **ส่งเฉพาะแถวที่เปลี่ยน** และรับความเปลี่ยนแปลงจากเครื่องอื่นผ่าน Realtime
- ถ้าอินเทอร์เน็ตหลุด หน้าเว็บยังใช้ข้อมูลที่แคชไว้ในเครื่องได้ตามปกติ
- ลบพนักงานในแอปจะลบเฉพาะสิทธิ์การใช้งาน **บัญชีล็อกอินยังอยู่ใน Supabase Auth**
  ถ้าต้องการลบถาวร ให้ลบที่ Authentication → Users ด้วย
- เปลี่ยนรหัสผ่านพนักงานแทนกันไม่ได้ (เข้ารหัสไว้) ใช้ปุ่ม **ส่งลิงก์ตั้งรหัสผ่านใหม่** ทางอีเมลแทน

## ข้อควรทราบ

- ข้อมูลเก็บใน **localStorage ของเบราว์เซอร์เครื่องนั้น** — เหมาะกับการใช้ในร้าน 1 เครื่อง
  ควรกด "ดาวน์โหลดไฟล์สำรอง" สัปดาห์ละครั้งและเก็บไว้บน OneDrive
- หากต้องการให้พนักงานหลายเครื่องเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์
  ต้องต่อฐานข้อมูลบนเซิร์ฟเวอร์เพิ่ม (โครงสร้างข้อมูลใน `store.js` ออกแบบให้ย้ายไป API ได้)
- ระบบรหัสผ่านใช้การเข้ารหัสอย่างง่าย เหมาะกับการกันคนในร้านเปิดดูกันเอง
  ไม่ใช่ระบบความปลอดภัยระดับอินเทอร์เน็ต

### ถ้าต้องการเปิดเป็นเว็บเซิร์ฟเวอร์ (แนะนำเมื่อจะเปิดจากมือถือในร้าน)

## สิ่งที่แนะนำให้ทำต่อ (ยังไม่ได้ทำในเวอร์ชันนี้)

1. **ระบบสมาชิก/ลูกค้าประจำ** — เก็บประวัติการซื้อรายคน แต้มสะสม ส่งโปรฯ วันเกิด
2. **รายงานสรุปรายเดือน + เปรียบเทียบเดือนต่อเดือน** และคำนวณคอมมิชชั่นพนักงานอัตโนมัติ
3. **บาร์โค้ด/QR จริง** — พิมพ์สติกเกอร์ติดสินค้าและสแกนขายได้เร็วขึ้น
4. **ชำระเงินออนไลน์** — QR PromptPay ในหน้า order.html พร้อมแนบสลิป
5. **แจ้งเตือนออเดอร์ใหม่เข้า LINE Notify** เพื่อไม่พลาดลูกค้า
6. **ย้ายข้อมูลขึ้นเซิร์ฟเวอร์** เมื่อมีมากกว่า 1 สาขาหรือหลายเครื่อง
